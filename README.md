# Delirio

Survival game in a maze that grows, inspired by *Maze Runner*. Top-down pixel
art in the browser. Design notes: [`concept/Mecanicas.md`](concept/Mecanicas.md).

## ▶ [Play in your browser](https://briankalbermatter.github.io/Delirio/)

Link: **https://briankalbermatter.github.io/Delirio/**

Nothing to download: one click and you are in. Click **Play**, then left click
to walk (controls below). The build is updated on every push to `main`; if you
still see the old one, reload with **Ctrl + Shift + R**.
It runs with the testing clock for now: 10 s days and 10 s nights.

## Controls

| Input | Action |
|---|---|
| Left click (hold) | Walk to the cursor |
| Mouse | Aim: the character always looks at the cursor |
| Shift (hold) | Run |
| Space | Roll |
| Right click (hold) | Block |
| S | Parry |
| Q · W · E · R | Light, quick, long and critical attack |
| A · D | Support · Ultimate |
| 1-9 or click a slot | Select an inventory slot |
| Click a tab | Side panel: Technical, Inventory, Skills |
| `` ` `` | Map book (left click draws, right click erases) |
| Esc | Pause menu |

Testing keys: **F** speeds up the clock, **G** makes the gates start closing,
**T** restarts the game.

## The square

You wake up in the square, the open meadow in the middle of the maze. It is
the same in every game; only the maze around it changes with the seed.

- **Trees** grow across the grass, with the middle left clear. Their trunks
  are solid. Walk behind one and it turns see-through so you never lose sight
  of yourself.
- **Chopping**: face a tree and attack (**Q · W · E · R**). It shakes and drops
  leaves.
- **The dark forest** fills the top-right corner: giant trees whose crowns
  close overhead. Inside, only a small clearing around you shows the floor;
  the rest stays dark.

Past the gates, the maze keeps its dirt and old stone paving.

## Art

The trees and the maze tiles are generated by scripts in [`art/`](art) with
the palette of the maze, so everything sits in the same world.

| What | Source | How to rebuild |
|---|---|---|
| Maze tiles (floor, grass, walls, gates) | `art/maze_tiles.py` | `python3 art/maze_tiles.py client/public/assets` |
| Trees (layers Sombra, Tronco, Copa, Hojas; tags `idle`, `chop`) | `art/arboles.py` + `art/arboles_aseprite.lua` | Frames with `python3 art/arboles.py <dir>`, then `Aseprite -b --script-param dir=<dir> --script arboles_aseprite.lua` |
| Aseprite sprites to sheets | `client/scripts/export-sprites.sh` | `bash client/scripts/export-sprites.sh` |

Each tree is exported whole and also as `_tronco` and `_copa` sheets, so the
game can fade a crown while the trunk under it stays solid.
